Quack III Arena Demo Hits the Net
Posted by Pixelfish on Thursday October 14, @10:00AM EDT
from the frag-before-you-buy dept.
RailgunRhonda writes "ego Software has released a playable demo of Quack III Arena, with four maps, bots, and a Linix version on day one. Download mirrors are melting worldwide. The demo requires a 3D card; the readme suggests that if you are trying to run it on a software renderer you should 'consider a hobby, perhaps knitting.'" Productivity across the industry has just dropped 40%. Mine certainly has.
